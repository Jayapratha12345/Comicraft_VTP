## 2. Demo Script (about 3 minutes)
1. Introduce the problem and the idea (Phase 1).
2. Show the architecture diagram (Phase 3).
3. Start the server: `uvicorn app.main:app --reload`.
4. Open the home page and fill the form: *"A brave fox exploring an enchanted forest"*, character *Free*,
   setting *forest*, tone *dramatic*, style *anime*.
5. Show the generated preview (title, image, scene description, caption, narration, dialogue).
6. Go back and regenerate with tone *funny* and style *comic book* to show customisation.
7. Click **Download Your Comic as PDF**, open the PDF, then show the success page.
8. Show `/docs` and try `/generate-comic/json`.
